# Data contracts — every schema in one place

The whole pipeline is glued by a handful of small, explicit JSON/TS shapes. Author them
against **raw source time**; the renderer re-anchors everything after cuts and speed-up. All
times are milliseconds unless a field name says `Frames`.

## Per-fragment directory (`fragments/<id>/`)

A directory is a fragment **iff it contains `story.md`**. The review board and `ingest.mjs`
discover fragments by scanning for it.

```
fragments/<id>/
  story.md              # beats, events, viewport, VO mapping — the human-readable spec
  meta.json             # index card (below)
  raw/
    take.mp4|.webm      # primary camera
    take-b.mp4|.webm    # secondary camera (only if the story is double-shot)
    events.json         # the event timeline (below) — REQUIRED; ingest skips a fragment without it
  narration/
    lines.json          # [{ id, text, voice?, speed? }]  → tts.mjs writes <id>.mp3
    01.mp3 …            # one file per line id
  captions.json         # [{ t0Ms, t1Ms, text, audio }]   subtitle cues bound to narration
  cuts.json             # [{ fromMs, toMs }]               spans of raw to DELETE
```

### `meta.json`
```jsonc
{ "title": "给 idea 一个身份",   // human title (Chinese in the gugu run)
  "desc":  "创建向导:引擎可选…",  // one-line description
  "act":   "幕一",              // owning act — buckets on the board (序幕/幕一/…)
  "order": 2,                   // sort order within the film
  "role":  "主线",             // 主线 (main line) / supporting / …
  "vo":    [2, 3] }            // screenplay VO line numbers this fragment carries
```

### `raw/events.json`  (`EventsFile`)
The event timeline: timestamped labels, optional focus boxes, optional zoom whitelist flag.
```jsonc
{ "video": "take.webm",
  "viewport": { "w": 1600, "h": 1000 },   // CSS coords the boxes live in
  "events": [
    { "tMs": 4200,                        // ms from recording start
      "label": "search-result",
      "box": { "x": 420, "y": 180, "width": 360, "height": 120 },  // locator.boundingBox()
      "zoom": true,                       // whitelist: only zoom:true events push in
      "measuredVideoMs": 18320 }          // optional: true in-video time (corrects webm VFR drift)
  ] }
```
Rules: a box-less event is a pure time marker (no camera move). **End events (`end`, `end-*`)
carry no box** — the camera auto-returns to wide. If *any* event has a `zoom` field, the camera
becomes whitelist-gated (only `zoom:true` pushes in); legacy footage with no flags keeps
"any box zooms."

### `captions.json`  (`Caption[]`)
```jsonc
[ { "t0Ms": 2000, "t1Ms": 5400,
    "text": "加朋友不用手机号——一个 ID 就够。",
    "audio": "01.mp3",          // relative to narration/ ; generated by tts.mjs
    "video": "take-b.webm" } ]  // optional: pins caption to a specific camera (multi-cam)
```
Each cue's `t1Ms - t0Ms` should be **≥ its mp3 duration + 400ms** (`afinfo <mp3>` / `ffprobe`).

### `narration/lines.json`
```jsonc
[ { "id": "01", "text": "…", "voice": "Chinese (Mandarin)_Reliable_Executive", "speed": 1.18 } ]
```
`tts.mjs --lines lines.json --outdir narration/` deterministically maps `id → <id>.mp3`.
Per-line `voice`/`speed` override CLI defaults. One voice for the whole film.

## Renderer manifest (`ingest.mjs` output → `renderer/src/manifest.ts`)

`ingest.mjs` copies each fragment's assets into `renderer/public/frag/<id>/`, cleans null
boxes, rewrites paths to web-served locations, and regenerates a typed `FragmentEntry[]`.
Multi-camera: if events carry different `video` fields, the fragment fans into `<id>--A`
(primary) and `<id>--B`.

```ts
type Box     = { x: number; y: number; width: number; height: number }   // video coords
type CamEvent = { tMs: number; label: string; box?: Box; measuredVideoMs?: number; zoom?: boolean }
type Caption  = { t0Ms: number; t1Ms: number; text: string; audio?: string }
type FragmentEntry = {
  id: string; title: string;
  src: string;                       // "frag/<id>/take.webm" (web-served)
  viewport: { w: number; h: number };
  events: CamEvent[];
  captions: Caption[];
  cuts?: { fromMs: number; toMs: number }[];
  segments?: { from: number; to: number }[];   // derived kept windows
  rate?: number;                     // playbackRate (final cut sets 1.25)
}
```

## Capture output (recorder → assembler)

`ShotLoopRecorder.stop()` writes, alongside `frames/fNNNNNN.jpg`:
```jsonc
// frames.json
{ "endTsMs": <epoch>, "frames": [ { "file": "f000001.jpg", "tsMs": <epoch> } ] }
```
The `Act` capture skeleton writes the semantic timeline in epoch time:
```jsonc
// events-epoch.json
{ "meta": { "act": "act1", "viewport": { "w": 1600, "h": 1000 }, "scale": 2 },
  "events": [ { "tsMs": <epoch>, "label": "send", "box": { … } | null, "zoom": true } ] }
```
`promo-assemble.mjs <actDir> --name actN` reads `frames.json`, builds an ffconcat where each
frame's `duration` = gap to the next frame's `tsMs`, encodes libx264 (`--crf 13 --fps 30`
defaults), and emits `actN.mp4` + `actN.events.json` with events **rebased** to video-relative
`tMs = epoch − firstFrameEpoch`. (Warns if bitrate < 8 Mbps — normal for mostly-static frames
under constant-quality CRF; judge clarity by sampled frames, not bitrate.)

## The final cut — `cutlist.ts` (single source of truth)

```ts
const FPS = 30, FADE_FRAMES = 12, RATE = 1.25          // video plays 1.25×; VO/BGM unchanged
type VoId = string
const VO_TABLE: Record<VoId, { text: string; durMs: number; src: string }> = { … }  // ffprobe-measured
const BGM = { src, skipSeconds: 15, baseVolume: 0.13, duckRatio: 0.35, duckRampFrames: 9 }

type VoCue = { vo: VoId; atMs: number }                // atMs on the segment's OUTPUT timeline
type SynthSegSpec = { kind: "synth"; id: string; comp: string; durationFrames: number
  trimStartFrames?: number; duckFrames?: [number, number][]
  embeddedVos?: { vo: VoId; atFrames: number }[]; vos?: VoCue[]; transitionAfter?: "fade" | "cut" }
type VideoSegSpec = { kind: "video"; id: string; src: string; keepMs: { fromMs; toMs }[]
  manifestId?: string; eventsFile?: string; frame?: { cx; cy; z }   // static pinned pose
  vos?: VoCue[]; transitionAfter?: "fade" | "cut" }
const CUTLIST: (SynthSegSpec | VideoSegSpec)[] = [ … ]  // the ordered edit
```

`layoutCutlist()` computes at compile time: absolute segment `starts[]` (subtracting
`FADE_FRAMES` on fade joins), `totalFrames`, a global VO `cues[]` (external `vos` via
`atMs→frames` + `VO_TABLE.durMs`; synth `embeddedVos` via `atFrames`), BGM `duckWindows: [a,b][]`,
and `ctaStartFrame`. Both `FinalCut.tsx` and `scripts/final-cut-qa.mjs` import this — one
geometry, never duplicated.

**RATE semantics:** video segments play at 1.25×; `keepMs` and event anchors stay in *source*
time; output frames = source / RATE; VO audio is unchanged (no pitch shift) and re-anchored to
the remapped beat points; BGM is unchanged.

## Review feedback (`review/feedback.jsonl`, append-only)

```jsonc
{ "ts": "<ISO, server-added>", "kind": "fragment" | "story" | "vo" | "music",
  "id": "<artifact-id?>", "verdict": "note" | "reject",
  "pick": "<variant-name?>", "comment": "<text>", "who": "<reviewer>" }
```
No `approve` verdict exists — approval is implicit (no open `reject` newer than the artifact's
latest render). Full protocol + the mtime-derived status state machine: `review-loop.md`.
